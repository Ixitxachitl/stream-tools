Adding a tool to OBS

Browser source in 4 steps

  1. Add a Browser source In your scene's Sources list, click + → Browser, give it a name and press OK.
  2. Paste the tool's link Put the tool's URL in the URL box. Set Width 1920 and Height 1080 (or your canvas size).
  3. Set it up from inside OBS Right-click the source → Interact. That opens a window where you can click the tool's settings, just like a normal web page.
  4. Go live! Settings are saved inside that browser source, so they'll still be there next stream.

Good to know

  • Everything runs in the browser source — nothing to install, no login.
  • OBS keeps its own browser storage, so settings you make in Chrome or Firefox don't carry over. Use Interact to set up the copy in OBS (or use a setup link, for the chat overlays).
  • Using Streamlabs Desktop, Meld or XSplit? They all have a browser / web-page source that works the same way.
  • If a source gets stuck, open its properties and press Refresh cache of current page.
