Adding a tool to OBS

Browser source in 4 steps

  1. Add a Browser source In your scene's Sources list, click + → Browser, give it a name and press OK.
  2. Paste the tool's link Put the tool's URL in the URL box. Set Width 1920 and Height 1080 (or your canvas size).
  3. Set it up from inside OBS Right-click the source → Interact. That opens a window where you can click the tool's settings, just like a normal web page.
  4. Go live! Settings are saved inside that browser source, so they'll still be there next stream.

Good to know

  • Everything runs in the browser source — nothing to install, no login.
  • OBS keeps its own browser storage, so settings you make in Chrome or Firefox don't carry over. Use Interact to set up the copy in OBS (or use a setup link, for the chat overlays).
  • Using Streamlabs Desktop, Meld or XSplit? They all have a browser / web-page source that works the same way.
  • If a source gets stuck, open its properties and press Refresh cache of current page.

Desktop apps

Desktop app

StreamEdge v0.1.34

A Twitch client for small ultrawide second screens. Your live follows, the stream and chat sit side by side in one short row, and the player stays close to live, so you can keep up with chat while you play. On Windows, hover over the video for the stream's title, game, viewers and uptime. Log in with Twitch to see who's live and chat.

  • Windows
  • macOS
  • Linux
  • Twitch
  • Free & open source
Windows macOS (Apple silicon) Linux x64 Linux ARM64 Source & all releases ↗

Unzip and run, no installer. On macOS install mpv first (brew install mpv); on Linux install your distribution's libmpv package (for example sudo apt install libmpv2).

Desktop app

Desktop Overlay v0.2.4

Like an OBS browser source, but on your desktop. Put any of the tools above, any web page, a local .html file or your own HTML over everything else, see-through wherever the page is. Unlock an overlay to drag and resize it (it snaps to the screen and to other overlays), lock it and clicks go straight through, fit it to its page, or let it fill a screen and leave the taskbar clear. It also comes with a little pixel-font stats panel: CPU, GPU, video memory and the frame rate of whatever game is in focus, on your desktop or as a browser source in OBS. It lives in the system tray, where every overlay is one click to show or hide.

  • Windows
  • Any web page
  • Free & open source
Windows Source & all releases ↗

Unzip and run Desktop Overlay.exe, no installer. Windows 10 and 11. Overlays show over games in borderless or windowed fullscreen, not in exclusive fullscreen.
